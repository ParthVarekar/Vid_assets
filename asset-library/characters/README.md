# Character stills

Reference images of Quill, Ink and Chalk, rendered from the 3D models in `src/world3d/` (no hand edits). Use them for review, for briefs and as a visual guide. They are JPEG copies; the lossless PNG originals are regenerated by the commands below.

| File | What it shows | Made by |
| --- | --- | --- |
| `turnaround-sheet.jpg` | Each bird from the front, three-quarter, side and back | `node scripts/lookdev/render-lookdev.mjs out/lookdev/gate1 --scale=2` |
| `lineup.jpg` | The trio side by side on the studio sweep | `Lookdev-Lineup` composition |
| `quill-closeup.jpg`, `ink-closeup.jpg`, `chalk-closeup.jpg` | Face close-ups: eyes, beak, fur | `Closeup-Quill`, `Closeup-Ink`, `Closeup-Chalk` |
| `expressions.jpg` | All 12 expressions, every bird | `PoseSheet-Expressions` |
| `gestures.jpg` | All 12 gestures, every bird, turned 20° | `PoseSheet-Gestures` |
| `rig-channels.jpg` | Each rig channel at its minimum, default and maximum (Quill) | `RigSheet`, via `npm run docs:rig` |

Lighting is the studio rig in `src/world3d/lighting.ts`. The birds are described in `docs/CHARACTER-BIBLE.md`, and the controls in `docs/RIG-REFERENCE.md`.
